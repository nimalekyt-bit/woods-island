# Безопасность и приватность

Репозиторий закрыт. Сообщения о проблемах оставляй в приватных issues или
направляй владельцу: https://t.me/woodskilla.

Не прикладывай API-ключи, secrets.json, личную историю буфера, чат, базы или
полный app.log без удаления чувствительных данных. Для воспроизведения
используй отдельный профиль и минимальный фрагмент лога.

Ключи локально шифруются Windows DPAPI; выбранный AI-провайдер получает
только явно отправленные ему запросы. Источники сетевых данных и ограничения
перечислены в документации функциональной приёмки.
