# Безопасность и приватность

Об уязвимостях сообщай через [GitHub Security Advisories](https://github.com/nimalekyt-bit/woods-island/security/advisories/new)
или лично [Woods](https://t.me/woodskilla). Ошибки без чувствительных данных
можно описать в обычном issue.

Не прикладывай API-ключи, secrets.json, личную историю буфера, чат, базы или
полный app.log без удаления чувствительных данных. Для воспроизведения
используй отдельный профиль и минимальный фрагмент лога.

Настройки и данные хранятся локально. API-ключи защищены Windows DPAPI.
Запросы ИИ отправляются выбранному пользователем провайдеру; погода использует
MET Norway и поиск мест OpenStreetMap/Nominatim. Экспорт заметок в Obsidian
запускается пользователем и требует выбора папки.
