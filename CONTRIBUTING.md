# Работа с проектом

Владелец: Woods / @nimalekyt-bit. Репозиторий приватный; его видимость,
публичные релизы и приглашения другим аккаунтам меняются только по отдельному
решению владельца.

Все коммиты отправляются от авторизованного аккаунта владельца. Author и
committer должны использовать его подтверждённый email либо GitHub noreply
`272979364+nimalekyt-bit@users.noreply.github.com`. Не добавлять Co-authored-by
других людей, ботов или ИИ. Main содержит историю владельца.
Проверка перед push: `pnpm check:authors`.

Работай в ветке; задачи бери из штабного TASKS.md. Не коммить личные настройки,
ключи, базы, логи, записи экрана, готовые EXE, target, node_modules и .env.
После кода выполняй pnpm build и соответствующие Rust/hooks/native проверки.
Успех подтверждается exit 0, реальным результатом и границами приёмки.

Новые дополнения
frontend пиши читаемо в woods-extensions.js. Не заменяй произвольные куски
минифицированного runtime: используй уникальный якорь и проверку количества.

Native QA только пассивная: не двигать мышь, не вводить аппаратные клавиши,
не захватывать фокус и не регистрировать хоткеи. Крупные изменения отражай
в Obsidian и документации приёмки.
