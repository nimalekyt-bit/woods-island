# Woods Island 1.0.0 — приватная тестовая сборка

Пилюля, музыка, буфер, заметки/Obsidian, погода и экранные инструменты
для Windows 10/11 x64. Все функции и 25 персонажей доступны без активации;
для внешнего ИИ используется собственный ключ или локальная модель.

## Исправления

- Устранены ложные «8 файлов»: старые Steam-очереди и дубли библиотек
  не показываются как загрузка. Проверяются клиент, флаги и изменение байтов;
  зависшие partial/crdownload тоже исчезают из индикатора.
- Погода открывается без падения: совместимый forecast, Часы/Неделя,
  замена старого cache, смена единиц и обработка неверных данных.
- Масштаб 80–200% меняет настоящий размер, DPI/zoom и область взаимодействия.
- Убраны прозрачная подложка и исчезновение пилюли при наведении.
- Яндекс Музыка Mod показывает название, обложку и прогресс через Woods connector.
- About и настройки адаптированы под Woods, иконка About — информация в круге.
- Исправлены WinRT startup/controls, аудиоустройства, события и сохранение данных.

## Запуск

Распакуй Woods-Island-1.0.0-windows-x64.zip и запусти woods-island.exe.
Оставь bin рядом с EXE для записи MP4/GIF. Нужен WebView2 Runtime.
Настройки/SQLite: %APPDATA%/woods-island. Обновление комплекта — вручную.
Сборка доступна только пользователям с доступом к приватному репозиторию.

с OBS Scrobbler. Для неизвестного города используется UTC/ручной offset.

публичное распространение не включено этой приватной сборкой.
