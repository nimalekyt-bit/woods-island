# Woods Island 1.0.0 — приватная тестовая сборка

Пилюля, музыка, буфер, заметки/Obsidian, погода и экранные инструменты
для Windows 10/11 x64. Все функции и 25 персонажей доступны без активации;
для внешнего ИИ используется собственный ключ или локальная модель.

## Исправления

- «Без персонажа» сохраняет обычную форму даже при включённом liquidWith; размер «Обычный/Крупный» управляет размером персонажа.
- Пауза обозначена на обложке в обычной пилюле и режиме названия; прогресс названия останавливается сразу. Уменьшение начинается через 2,5 секунды, повторные метаданные не продлевают ожидание.
- Выбор/каталог персонажей, таймер музыки и компонент названия перенесены в TS/TSX; новые регрессии включены в CI.
- Production UI собирается Vite из runtime/: компоненты, типизированный IPC с проверкой Rust-контрактов, раздельные vendor-модули и загрузка редактора заметок при открытии.
- PPTX-вложения читают текст в порядке презентации; Claude поддерживает одиночный/множественный выбор с сохранением метаданных исходного запроса.
- Windows Store inventory и запуск используют Shell/ActivationManager; иконки EXE/LNK/Store извлекаются Windows Shell и кэшируются.
- Поддержаны службы AmneziaWG/WireGuard и пользовательские VPN-команды. Найденные GUI-клиенты открываются из панели; автоматическое переключение доступно при наличии управляемой службы/команды.
- Убраны неизменные события загрузок/тихого спектра и повторный опрос панели управления; ограничены кэши иконок и чтение файлов агентов.
- Настройки и редактор изображений создаются при открытии; закрытие освобождает их WebView-процессы.

- Быстрое чтение состояний управления с обновлением в фоне; физический Ethernet
  отображается с реальным состоянием подключения. Карточка открывает параметры Windows.
- Windows VPN перечисляются нативным RAS API; исправлена обработка команды из карточки.

- Эквалайзер слушает выход активного плеера, в том числе когда Windows
  направляет музыку мимо системного устройства по умолчанию. Явный выбор
  аудиовыхода имеет приоритет; громкость и системный маршрут не меняются.
- Синхронизация текста песни: активная строка выделяется и меняется по
  позиции трека в плеере, свёрнутой пилюле и на «Главной». Исправлено поле
  ms в LRCLIB-контракте, добавлена обработка сетевых ошибок.
- Устранены ложные «8 файлов»: старые Steam-очереди и дубли библиотек
  не показываются как загрузка. Проверяются клиент, флаги и изменение байтов;
  зависшие partial/crdownload тоже исчезают из индикатора.
- Погода открывается без падения: совместимый forecast, Часы/Неделя,
  замена старого cache, смена единиц и обработка неверных данных.
- Масштаб 80–200% меняет настоящий размер, DPI/zoom и область взаимодействия.
- Убраны прозрачная подложка и исчезновение пилюли при наведении.
- Яндекс Музыка Mod показывает название, обложку и прогресс через Woods connector.
- About и настройки адаптированы под Woods, иконка About — информация в круге.
- Исправлены WinRT startup/controls, аудиоустройства, события и сохранение данных.

## Запуск

Распакуй Woods-Island-1.0.0-windows-x64.zip и запусти woods-island.exe.
Оставь bin рядом с EXE для записи MP4/GIF. Нужен WebView2 Runtime.
Настройки/SQLite: %APPDATA%/woods-island. Обновление комплекта — вручную.
Сборка доступна только пользователям с доступом к приватному репозиторию.
