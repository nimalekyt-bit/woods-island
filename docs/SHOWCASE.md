# Визуальная документация Woods Island

README: центрированная шапка, бейджи, RU/EN, Home, персонажи, погода,
сетка вкладок, установка и рабочие инструменты.

Скриншоты docs/img/ru и en показывают пустые состояния runtime:
без выбранного города, музыки, названий устройств, файлов, заметок,
чатов и событий владельца. Для снимков используется отдельный временный
профиль в пассивном режиме; поступление данных в отображение отключено.
Аппаратный ввод и фокус не используются.

Изображения с данными рабочего компьютера не включаются в репозиторий
и сайт. После обновления снимков проверить каждый кадр визуально и
сверить отсутствие персональных строк до публикации.
