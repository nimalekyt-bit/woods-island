# Woods Island — форма, пауза и исходники, TASK-1418

## Поведение

«Обычный/Крупный» относится к размеру персонажа. «Без персонажа» теперь сохраняет
простую форму, включая `liquidWith=true`. Музыкальный персонаж применяется только
при `media.playing=true`; на паузе сразу возвращается обычный выбор.

В режиме названия и обычной media-пилюле на обложке появляется значок паузы.
Прогресс в режиме названия прекращает интерполяцию сразу. Пилюля сохраняет
музыкальный интерфейс 2500 мс с начала паузы, после чего плавно уменьшается.
Частые paused metadata не продлевают таймер. Resume отменяет его; отсутствие
media убирает активный интерфейс сразу. Начальное paused media не раскрывает пилюлю.

## Причины и исправление

Старая политика формы учитывала `liquidWith` без исключения `none`.
Обработчик `media:update` пересоздавал 2500-мс таймер при каждой paused metadata,
поэтому источник с обновлениями чаще 2,5 секунды мог удерживать пилюлю бесконечно.
Название, обложка и полоса прогресса не показывали паузу; ширина полосы продолжала
CSS-переход ещё секунду.

`runtime/characters/selection.ts` и `runtime/media/activity.ts` содержат теперь
читаемые политики без React/store dependencies. `catalog.ts` содержит 25 описаний,
локализацию и bounding boxes. `components/CollapsedTrack.tsx` содержит название,
PauseBadge и прогресс; прежний Home вызывает компонент через небольшой store adapter.
Pinned React и Motion сохраняются через typed bridges. Весь compat JS пока не перенесён.

Персонажи процедурные SVG с `build`/`draw`; расширение описано в RUNTIME.md.
Новые персонажи в этом изменении не добавлялись. Импорт произвольных персонажей
пользователем пока отсутствует.

## Проверка

Фактические результаты итогового release хранятся в acceptance-media-pause-20261112.json.
Регрессии с точными часами покрывают поток paused metadata, resume, missing media,
cleanup, none/liquidWith, музыкальный выбор и расширяемость каталога. Нативный сценарий
подаёт только isolated fixture каждые 120 мс, проверяет значок/остановку прогресса,
форму и реальное уменьшение; личная музыка и её управление не используются.

Показатели памяти TASK-1417 остаются предыдущим сравнением: private bytes −22–28%.
Новое изменение не сопровождается заявлением о дополнительном снижении CPU/RAM.
Аппаратные действия, реальные Store activation, VPN connect и внешние AI по-прежнему
ограничены рамками пассивной приёмки. Пользовательские screenshots не публикуются.
