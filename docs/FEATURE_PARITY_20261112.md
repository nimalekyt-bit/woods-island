## Исправления этой проверки

- Lyrics-пилюля резервирует ширину по всей песне, до 528 px текста (округление по 16 px);
  общий предел геометрии остаётся 680 px. Короткие строки не сжимают остров.
  Строки занимают фиксированные 30 px, допускают два ряда и перенос слова
  без пробелов. Вход/выход текста занимает 240 ms без blur; размер меняется
  с почти критически затухающей пружиной, без выраженного отскока.
- `showDownloads=false` действительно подавляет карточку завершённой загрузки.
  Прогресс управляется отдельными `downloadsInPill` / `steamDownloads`.
- `agentsAsk=false` действительно подавляет вопросы ИИ в UI. Ответы автоматически
  не отправляются: разрешение команды остаётся действием пользователя.
- `openOnHover=false` по умолчанию сохраняет открытие по клику. Новый переключатель
  включает открытие при наведении, после чего `hoverDelayMs` действует.
  `collapseDelayMs` применяется при уходе курсора из раскрытой панели.
- `checkUpdates` теперь управляет фоновым запросом при запуске и каждые 6 часов.
  В пассивном QA фоновая сеть отключена. Приватный GitHub без авторизации
  возвращает 404; успешная доставка обновления для обычного пользователя
  этим изменением не обеспечивается. Ручной запрос остаётся доступен.
- Кнопка открытия страницы обновлений больше не включает бесконечный индикатор
  загрузки: backend открывает страницу, а не скачивает установщик.

## Функции оригинала и фактическая реализация

**Пилюля, жидкий край и персонажи.** Реализованы 25 персонажей, реакция на
курсор/звук/сон/события, liquidWith и FFT эквалайзер. Формы notch/capsule,
масштаб/DPI, прозрачность и свёрнутая/раскрытая геометрия проверяются runtime.
Приёмка дополнена последовательным монтированием всех 25 персонажей.
Музыкальные режимы normal/title/player/lyrics, синхронизация текста,
перемотка позиции тестового источника и пауза проверяются отдельно.

**Музыка.** GSMTC и установленный Яндекс connector, обложки, прогресс,
выбор плеера, громкость сессии и наблюдение выбранного output реализованы.
Яндекс connector v3 не поддерживает seek: действие отключено. Next/prev/play
в плеере владельца не нажимались при QA. Новый прогон использует отдельный
loopback-порт; тестовая перемотка не означает появления seek в connector v3.

**Часы, батарея, раскладка, Caps Lock, виртуальные столы.** Backend передаёт
реальное состояние; frontend применяет showClock/clockSeconds/clockFormat,
showBattery/showLayout/layoutInPill/showCaps/desktopInPill. Нет батареи — нет
выдуманного уровня. Смена раскладки и Caps Lock аппаратными клавишами в QA
не производилась; события и Windows API проверены по коду.

**Приватность.** Микрофон/камера получают реальные системные статусы;
showPrivacy управляет индикаторами. Mute и выбор input/output подключены.
Нативный монитор читает выбранное устройство; Windows default не переназначается.
Физическое отключение микрофона и камеры не выполнялось тестом.

**Буфер обмена.** Текст, изображения, файлы, поиск, закрепление, очистка,
лимит и clipExcludedApps работают через SQLite и Windows clipboard.
Rust проверяет повторное копирование, сортировку, pruning и pin.
pasteOnClick и plain paste подключены к настоящей вставке; аппаратный Ctrl+V
в чужое окно тестом не отправляется. Полная проверка каждого редактора отсутствует.

**Полка и запуск приложений.** Сохранение файлов, список, удаление, clear,
native drag, ссылки/URI, группы и индивидуальные hotkeys реализованы.
Round-trip файлов/групп/ссылки проверяется runtime. Drag в стороннюю программу,
запуск личных приложений и UAC не инициируются тестом.

**Текстовые инструменты.** Смена ошибочной раскладки, регистр, транслитерация,
JSON/Base64/URL, создание QR и ИИ-действия находятся в runtime frontend.
Они не заменены backend-заглушками. Проверка всех преобразований во всех
языках отдельно не автоматизирована; для ИИ используются protocol fixtures.

**Командная строка.** Программы, recent, файлы/папки, калькулятор, конвертер,
валютные курсы, web search, timer/reminder и cmd/PowerShell реализованы.
paletteFiles/paletteFolders/searchEngine/searchUrl подключены. Inventory
Windows Store ограничен ярлыками Start Menu: отдельного полного перечисления
AppX нет. Иконка из EXE/LNK не извлекается системным Shell API — palette_icon
читает файл изображения. Поиск обходом каталогов ограничен глубиной/количеством;
это не полноценный индексатор файловой системы.

**Заметки, таймер, напоминания.** Rich text, папки, сохранение, повторные
напоминания и звук реализованы в frontend + persistent files. Runtime
проверяет сохранение и restart; Obsidian export проверяет Markdown и отсутствие
перезаписи. Настоящий alarmSound не воспроизводится без действия владельца.

**Сеть и управление.** Wi-Fi inventory/password/подключение/отключение,
радиомодуль Bluetooth, Ethernet status/open Windows settings, системная тема,
lock/sleep/restart/shutdown/schedule реализованы. Ethernet и задержка проверены
TASK-1415. Сетевые подключения и питание владельца в QA не меняются.
Bluetooth battery всегда null, тип устройства other; переключение включает
службы устройства и не подтверждает итоговое переподключение. Это частичный паритет.

**VPN.** Реализованы Windows RAS и Cloudflare WARP. Автоматических адаптеров
Happ/v2RayTun/Karing/Mullvad/PIA/Windscribe/OpenVPN из оригинала нет.
Сохранение vpnCustomName/On/Off/Admin есть в UI, исполнения этих команд нет:
это реальная неработающая группа настроек. showVpn/vpnLookupIp подключены,
отключение IP lookup проверено. Успешный exit процесса RAS/WARP не подтверждает
стабильный туннель. Полный VPN-паритет отсутствует.

**Погода.** MET Norway, город, 24 hours/7 days, единицы, часовой пояс известных
городов, showWeather/weatherAlerts, cache и ошибки реализованы. Runtime
проверяет контракт и UI на MET fixture. Полного resolver часовых поясов нет;
weatherUtcOffset читается backend, но отсутствует в default_settings, поэтому
обычный settings_set его не сохраняет. Реальный прогноз может зависеть от сети.

**Снимки, OCR, QR, цвет.** PNG, область/экран, папка, копирование, markup,
OCR Windows RU/EN, распознавание QR, picker/history реализованы.
Runtime проверяет настоящий PNG, OCR и сохранение editor fixture;
shotDraw/screenshotDir и captureVisible имеют обработчики.
Проверка OCR не означает распознавания любого текста; QR/picker аппаратно
на экране владельца не запускались. Imgur/ImgBB имеют HTTP-клиент, но внешняя
загрузка с личным ключом не выполнялась.

**Запись экрана.** MP4/GIF через поставляемый FFmpeg, fps/quality/system/mic/both,
выбранный input/output и папка реализованы. MP4 с video/system audio
проверяется ffprobe. Все fps/quality и GIF не кодируются отдельными прогонами;
сохранение параметров не считается проверкой каждого кодека/устройства.

**ИИ-чат и вложения.** Контекст, streaming UTF-8, cancel, ошибки, список моделей,
DPAPI-ключ и локальный/OpenAI-compatible endpoint проверяются fixture.
PDF/DOCX/XLSX/plain text/images извлекаются. PPTX, бинарные DOC/XLS/PPT
не поддержаны, хотя PowerPoint указан в оригинале. Scanned PDF требует OCR.
Embedded web AI есть, но авторизация/капча всех сайтов не проверены.

**Голос в текст.** Выбранный микрофон, PCM/WAV, STT endpoint/model/language,
cancel и dictatePaste реализованы. WAV и безопасный endpoint проверены Rust.
Запись речи владельца и запрос к личному внешнему STT не запускались.

**ИИ-агенты и OBS.** CLI hooks сохраняют чужие configs; permission allow/deny
Claude работает на protocol fixture. Ответ `answer` с выбором вариантов
отклоняется backend: такие вопросы нужно отвечать в терминале. Codex notify
передаёт завершение; это не полный streaming каждого рабочего шага Codex.
OBS v5 handshake/auth/status проверяется fixture; живой стрим не переключается.

**Обновления.** Проверка release API подключена; загрузка и подписанная
автоустановка отсутствуют. updateInstall открывает страницу релизов.
Приватная публикация требует GitHub login и отличается от публичного оригинала.

## Настройки: итог сверки

Все 12 разделов UI проверяются в нативном settings WebView RU/EN.
Группа персонажей дополнена прогоном 25 значений. Статический реестр покрывает
122 default fields, включая динамические обращения по строковому ключу.
116 полей имеют ссылки в runtime, 4 поля custom VPN — только в settings UI,
2 поля не используются. Это статистика подключения, не процент исправности.
`hideForAppsMode` и `mascot` не имеют consumer и не показаны как отдельные
настройки текущего UI; это остаточные поля. Группа custom VPN показана, но
не действует. checkUpdates реализован, но приватность репозитория ограничивает
доставку; GPU acceleration требует перезапуска. Open delay действует только
при включённом openOnHover. Права notifications зависят от Windows.

Нативная регистрация hotkeys отключена в QA: конфликты с программами владельца
не провоцируются. Autostart меняется только в обычном профиле, тестовый профиль
не записывает Run registry. HideInFullscreen/hideForApps/keepForApps используют
реальную foreground telemetry; не выполнялся захват фокуса ради их тестирования.
Сохранение значения и отсутствие JS exceptions не объявляются доказательством
работы сети, питания, аппаратного ввода или стороннего облачного сервиса.
