# Woods Island — функциональная приёмка 12.11.2026

Проверка продолжает TASK-1413 и TASK-1414. Повод: сохранённый масштаб не менял остров,
играющая Яндекс Музыка отсутствовала в пилюле, настройки требовали адаптации.
Все GUI-проверки выполняются в отдельном профиле, без аппаратного ввода,
перехвата фокуса и регистрации глобальных сочетаний. Сайт не публиковался.

## Исправленные разрывы

- Эквалайзер следовал системному default output, хотя Windows направляла
  Яндекс Музыку в другой endpoint. На default уровень/полосы были нулевыми;
  отдельная проверка нашла активную музыкальную сессию на другом выходе.
  Теперь автоматический loopback следует устройству активного плеера;
  явный audioOutput сохраняет приоритет. Windows routing/volume не меняются.
  Реальный звук, свежие 8 полос и изменение SVG контура подтверждены
  нативным прогоном с WOODS_TEST_EXPECT_AUDIO=1; test tone не воспроизводился.
- Текст песни: LRCLIB timestamps теперь передаются как ms в миллисекундах,
  как ожидает renderer. Поле time оставляло активный индекс равным -1:
  строки были видны, но не выделялись и не менялись по времени.
  Разобраны повторные timestamps и порядок строк; HTTP 404 означает отсутствие
  текста, сетевые/серверные ошибки допускают повторный запрос.
  Проверены выделение, движение по времени, пауза и перемотка в обе стороны,
  плеер, свёрнутая lyrics-пилюля и «Главная». Fixture использует отдельный
  порт и не передаёт данные в запущенный плеер владельца.
- Индикатор загрузок: Steam проверяет наличие клиента, StateFlags и рост
  BytesDownloaded; старые очереди и ошибки не считаются активной загрузкой.
  Варианты пути библиотеки с разным регистром/разделителями и повторные appid
  не удваиваются. Пауза и остановившийся прогресс убирают индикатор.
  Старые partial/crdownload также требуют измеренного роста файла.
  Регрессии покрыты Rust и настоящим runtime; реальная проверка библиотек
  владельца без подставленных manifest вернула 0 загрузок вместо прежних 8.
- Погодная панель падала на старом формате данных: отсутствовал days,
  timestamps были в миллисекундах, MET symbol передавался вместо WMO code.
  Backend теперь выдаёт schemaVersion=2, now/24 hours/до 7 days, секунды,
  числовые коды и единицы. Старый cache отклоняется, frontend валидирует
  forecast и показывает ошибку вместо падения. Смена города/единиц запускает
  обновление и отбрасывает запоздалый ответ для предыдущих настроек.
  MET sunrise запрашивается отдельно; отсутствие солнца/UV показано честно.
- Масштаб 80–200% применяется к WebView zoom и физическому canvas 760×480.
  ReportPageScale измеряет реальный коэффициент CSS → physical; hit test,
  обрезка, курсор, центрирование и высокий режим используют тот же масштаб.
  Значение применяется немедленно и восстанавливается при запуске.
- В установленной Яндекс Музыке Mod Windows GSMTC возвращает 0 сессий.
  Уже установленный Woods-коннектор действительно посылает title/artist,
  position/duration, playing и coverUri на 127.0.0.1:3003. Встроен принимающий
  мост; метаданные старше 3 секунд исчезают. Плеер/клавиши автоматически
  не управляются. GSMTC остаётся основным транспортом для обычных плееров.
- Обложки из локального GSMTC и коннектора теперь вызывают media:cover.
  Ошибка Canvas SecurityError при извлечении цвета внешней обложки обработана.
- About: Woods Island, бесплатные функции, Obsidian, BYOK/локальные модели,
  Woods Personal Corp и подтверждённые контакты @woodskilla / nimalekyt-bit.
  Удалены покупка, лицензионная активация, истёкшая проба, чужая donation-кнопка,
  Pro-маркировка настроек и чужие новости в списке версий. RU и EN адаптированы.
  По замечанию владельца значок «О приложении» заменён со звёздочек на
  стандартную информацию в круге, с теми же размером и толщиной линий.
- Выбор аудиовыхода меняет устройство наблюдения и управления, сохраняя
  системный default. Выбор входа используется микрофоном/диктовкой;
  без выбранного входа mute применяется ко всем активным микрофонам.
  Громкость плеера умеет находить WASAPI-сессию коннектора без GSMTC.
- CaptureVisible управляет Windows display affinity; GPU acceleration
  отключается флагом WebView2 --disable-gpu после перезапуска.
- NotificationsAccess возвращает allowed/denied/unspecified/unavailable,
  как ожидает интерфейс. VpnLookupIp=false действительно исключает IP-запрос.
- DesktopInPill получает текущий индекс/имя/число столов из Explorer registry.
- SteamDownloads читает appmanifest/libraryfolders, измеряет дельту bytes,
  распознаёт завершение и соблюдает переключатель. Старые завершённые игры
  не превращаются в новые карточки.
- Завершение/отмена захвата удаляет замороженный frame, исключая повторное
  сохранение старого экрана. PrtScTaken больше не отправляет ложное сообщение
  «скриншот скопирован» при открытии настроек.
- Toggle плеера передаёт желаемое play/pause, уже вычисленное интерфейсом;
  это устраняет лишний toggle при задержках статуса Windows.
- Системные WinRT-команды выполняются в рабочих потоках. CoIncrementMTAUsage
  сохраняет MTA на время жизни приложения; иначе завершение стартового
  потока инвалидировало cached Radio factories и следующий controls_get
  падал с Windows access violation 0xC0000005. RoInitialize/RoUninitialize
  теперь сбалансированы для radios, notifications и OCR.

## Область проверки по разделам интерфейса

1. **О приложении:** бренд, бесплатный статус, отсутствие покупки/ключей,
   контакты и RU/EN проверяются в настоящем settings WebView.
2. **Персонажи:** extracted character engine, бесплатный доступ и отсутствие
   Pro-маркировки. Превью и все разделы монтируются без JS exceptions.
3. **Общее:** сохранение, масштаб вверх/вниз, DPI/clip, collapse/expand/hover,
   отсутствие подложки на реальном desktop; affinity и restart persistence.
4. **Клавиши:** parser/registration и конфликты реализованы. В приёмке
   регистрация выключена: клавиши и системный ввод владельца не перехватываются.
5. **ИИ:** models/SSE/UTF-8/attachments/cancel/errors и DPAPI; protocol fixture
   проверяет запросы. Это не проверка всех внешних провайдеров и личных ключей.
6. **Голос в текст:** PCM/WAV и выбранный вход подключены. Внешняя транскрипция
   реального микрофона не запускалась в фоне без действия пользователя.
7. **Погода:** открытие панели, Часы/Неделя, 24 часа/7 дней, замена старого cache,
   metric/imperial, UTC+3 для Брянска и recovery после некорректного события.
   Нативная проверка использует MET protocol fixture, не реальную погоду.
   Известные города получают UTC offset/DST, неизвестные — UTC либо ручной
   weatherUtcOffset; полного resolver часовых поясов нет. Доступность реального
   сетевого прогноза зависит от MET/Nominatim и отдельно не подтверждена.
8. **Звук:** реальный inventory/volume read/WASAPI FFT, выбранный endpoint,
   измеряемая player volume. Физический mute/routing в этой приёмке не меняются.
9. **Живые события:** Яндекс-трек/обложка/позиция и virtual desktop — реальные;
   Downloads/Steam — изменения временных файлов; OBS — protocol fixture;
   CLI hooks — отдельный временный agent-home. Push-notification permissions
   и реальные вопросы другого CLI не запрашиваются без действия владельца.
10. **Буфер обмена:** SQLite text/image/files, pin/recopy/prune/CRUD и ошибки;
    нативная вставка аппаратным Ctrl+V не запускается тестом.
11. **Модули:** Shelf/Launcher/groups/notes/chat/timer persistence,
    Obsidian Markdown export без перезаписи, PNG/MP4/редактор, Windows OCR.
    Переключение системной сети, питание и открытие внешних приложений
    не обозначаются проверенными только по возвращаемому bool.
12. **Обновления:** GitHub release API/error handling реализованы; сборки
    публикуются вручную в приватном репозитории. Подписанная автоматическая
    установка отсутствует. About показывает версии Woods Island.

## Совместимость Яндекс-коннектора

Мост поддерживает существующий connector v3 владельца: POST /track,
GET /cmd, POST /debug; listener привязан исключительно к loopback.
Порт можно переопределить WOODS_ISLAND_MUSIC_PORT. На других компьютерах
мост сам по себе не добавляет коннектор в Яндекс Музыку; обычный GSMTC
продолжает работать независимо. Код чужого плеера в этой доработке не изменялся.

Next/prev и play/pause передаются коннектору только по пользовательской
команде. Реальный трек во время проверки не переключался. Connector v3
не предоставляет seek; canSeek=false отключает действие перемотки вместо
ложного изменения позиции. Для GSMTC seeking продолжает работать.
Если порт 3003 занят отдельным OBS Scrobbler, bridge фиксирует ошибку в app.log;
одновременно два сервера на одном порту работать не могут.

## Управление и Ethernet — TASK-1415, 12.11.2026

Первый controls_get прежнего EXE занимал 1480 мс; Ethernet всегда был null.
Теперь запрос возвращает снимок без ожидания WinRT и VPN; фоновый монитор
обновляет состояния раз в 3 секунды. Радиомодули перечисляются одним вызовом,
Windows VPN — нативным RAS API вместо PowerShell, профили проверяются по типу VPN
и настоящему состоянию соединения. Исправлен префикс vpn: в controls_set.

GetIfTable2 выбирает физический Ethernet: тип Ethernet и HardwareInterface,
подключённый адаптер имеет приоритет. TAP/VPN/Hyper-V не подменяют кабель.
Карточка показывает Connected/Disconnected; нажатие открывает параметры Windows.
