# Геометрия и музыкальные компоненты — TASK-1420

В этом этапе перенесены расчёт размеров пилюли, выбор режима, параметры переходов
и основные взаимодействия в TypeScript. Normal media и folded lyrics теперь
имеют читаемые TSX-компоненты. Отрисовка остаётся React/WebView2/SVG.

## Изменения

- `runtime/island/sizing.ts`: размеры виджетов, слотов персонажей и четырёх вариантов
  media; прежние экспорты shared.js вызывают этот модуль.
- `geometry.ts`: приоритет palette/expanded/dictation/peek/recording/update/downloads/
  music/shelf/status/idle, размеры карточек и вопросов Claude, chat/palette и drag overlay.
- `transitions.ts`: пружины plain/liquid/lyrics, отдельная корректировка осей
  по величине изменения и округление ширины до двух физических пикселей.
- `interactions.ts`: hover, outside click, palette, hotkey tab и webAI hold через
  порты store. Переключение отменяет отложенное наведение, callback повторно
  проверяет текущий режим; dispose освобождает таймеры.
- `runtime/media/events.ts`: metadata/cover и фиксированный grace 2500 мс.
  Расчёт цвета старой обложки не может примениться к новому треку; ожидание
  новой обложки ограничено 4000 мс, таймеры отменяются при смене трека/dispose.
- `NormalMediaPill.tsx` и `LyricsMediaPill.tsx`: прежняя разметка, размеры и анимации.
  Lyrics публикует ширину по всей песне и сбрасывает её при размонтировании.

По скриншоту владельца исправлено положение паузы. Старые arbitrary Tailwind-классы
для badge отсутствовали в поставляемом CSS, поэтому браузер рисовал значок у baseline
под обложкой и обрезал его. Значок 14×14 px теперь расположен внутри правого нижнего
угла обложки через явные стили, с непрозрачным тёмным фоном и белыми полосками.
Title, normal и lyrics используют один компонент; нативная проверка контролирует
размер, попадание в границы обложки/пилюли и видимость на четырёх масштабах.

Runtime CSS пока содержит готовые utilities из дистрибутива. Новые arbitrary классы
не генерируются автоматически: добавляйте явные стили или собственные CSS-правила
и проверяйте computed styles в WebView2.

Нативные события функций capture/VPN/OBS и раскладка плиток Home остаются в compat.
Адаптер `useIslandGeometry` сохраняет существующие store subscriptions и передаёт
в TS текущие значения, включая измеренный Home. SVG build/draw — следующий TASK-1421.

## Проверка

Сравнение с функциями main `9a3d929` дало 98 304 совпадающих расчёта.
`scripts/fixtures/island-sizing.json` фиксирует 16 наборов параметров прежнего кода
для повторяемой регрессии. Тесты запускают production TS через общий loader.
Новые сценарии покрывают приоритет состояний, размеры/DPI/drop/lyrics, таймеры
наведения и паузы, запоздавший accent, cover-before-metadata и cleanup.

Итоговые команды, SHA256 EXE, количество нативных проверок и измерения переходов
хранятся в `acceptance-island-geometry-20261112.json`. Приёмка запускает Windows
WebView2 с отдельным профилем и metadata fixture; проверяет normal/title/lyrics,
face/slot, раскрытие и паузу при масштабах 80/100/150/200 процентов.

CPU/RAM в этом этапе не измерялись. TASK-1422 сравнит всю process tree в одинаковых
условиях; перенос на TypeScript сам по себе не подтверждает снижение нагрузки.
