# Woods Island: развитие после 1.3.1

Этот файл описывает рабочую версию. Наличие изменений здесь не означает,
что они уже входят в опубликованное обновление.

## Выпущено

1.3.1 опубликована. Исправления оформления настроек устройств вошли в неё.
Установщик и portable проверены по публичным хешам. Метаданные для сайта
сформировались автоматически. Проверка запуска сайта по расписанию остаётся
отдельным незавершённым этапом.

## Текущий блок

- Недавние города: до восьми вариантов, сохранение координат и часового пояса.
- Скрытие острова при пересечении с окном; исключения для выбранных программ.
- Приоритет списка «Оставлять», включая полный экран; учёт монитора острова.
- Настраиваемый выход от верхнего края над полным экраном.
- Освобождение клавиш инструментов и лаунчера для полноэкранных программ.
- Запись сочетаний: удерживаемые клавиши, цифровой блок, названия конфликтующих
  действий и временное освобождение сочетаний при редактировании.
- Выбор программ из открытых окон и добавление установленных браузеров.
- Дата в запросах ИИ, сообщения об ошибках RU/EN и HTTP/SOCKS5-прокси.
  Пароль прокси хранится через Windows DPAPI; локальные модели обходят прокси.
- Скрытие плееров при выборе источника и возвращение через настройки,
  включая закрытые плееры и коннектор Яндекс Музыки.
- ChatGPT в переключателе чата, настройках и поиске команд; сохранение выбора.

Сборка интерфейса, тесты настроек и браузерная проверка RU/EN прошли.
169 Rust-тестов и все 10 целевых нативных проверок текущего блока прошли.
Хеши 58 встроенных ресурсов совпали с проверенной сборкой интерфейса.
Проверка веб-чата
использует локальную страницу и не подтверждает вход в аккаунт провайдера.
Проверка записи сочетаний в браузере не подтверждает регистрацию Windows.

## Следующий блок в работе

- Торрент-загрузки: общий переключатель в «Живых событиях», выключен по умолчанию.
  Проверка владельца файла через Windows в отдельном потоке, ограниченная очередь,
  сохранение происхождения после переименования и защита от повторных уведомлений.
  Активные файлы читаются напрямую: размер в списке папки Windows может устареть
  до закрытия записывающей программы. Тестовый процесс не является реальным клиентом.
- Напоминания: даты словами RU/EN, варианты недель, сдвиг на день/15 минут,
  проверка календаря и сохранённых часов повторения. Сдвиг на день сохраняет
  местное время при переходе DST; невозможная дата не превращается в другой день.
- Название Woods Island в карточке обновления и результатах командной строки.
- Голосовая команда: отдельное назначаемое сочетание и действие командной строки,
  обработка результата RU/EN, выполнение найденного действия после короткого
  показа результата. Неопределённый результат остаётся в строке; редактирование
  и закрытие отменяют выполнение. Этот режим не вставляет текст в чужое окно
  и не заменяет буфер обмена.
- Бесплатность: стартовый статус без пробного периода, удаление текстов покупки,
  отсутствие проверки активации при открытии настроек. Событие со старым
  ограничивающим статусом не закрывает функции и персонажей.

Нативная проверка напоминаний RU/EN прошла: дата, сдвиги, варианты недели,
сохранение и повторное редактирование; элементы помещаются в боковую панель.
Подключение React исправлено и проверено с общим renderer Woods.
Торрент-фильтр прошёл Windows-проверку владельца файла, переключение из
настроек, показ в закрытой пилюле, переименование и обычную загрузку одновременно.
Писатель — отдельная наша фикстура; реальные торрент-клиенты ещё не проверены.
Все 127 регрессионных JS-тестов прошли, включая проверки истории выпусков,
настроек RU/EN и записи голосового сочетания. Восемь целевых проверок нативной
сборки прошли: встроенные ресурсы, напоминания, бесплатность, голосовая команда,
торрент-фильтр, Steam, отсутствие ошибок интерфейса и завершение приложения.
Голос проверялся синтетическим событием распознавания; настоящий микрофон,
STT и регистрация сочетания Windows ещё требуют проверки.
Новый релиз не опубликован.

## Оформление «О приложении» и история выпусков

Этот блок входит в общий перенос, как попросил владелец. Реализованы новая
композиция с маскотом Woods, сведения об авторе, бесплатность, карточки наших
возможностей и переход к обновлениям по кнопке версии. Убрано старое фиксированное
число персонажей. Настройки сохраняют общий тёмный стиль при обеих темах острова.

История берётся из `releases/<version>/release.json`; генератор регистрирует
все актуальные редакционные записи, а сборка проверяет свежесть списка.
Ранние выпуски Woods сохранены в `releases/archive.json`. В истории остаются
и списки, и исправления, описанные обычным текстом. Шаблоны версии подставляются;
установленная версия приходит из Tauri, предлагаемая — из updater. Кнопки
открывают соответствующий выпуск Woods. Неизвестная версия не подменяется
последней версией из архива.

Браузерная проверка RU/EN прошла: 820/660 пикселей, масштаб 100/125%, обе темы
острова, наведение, управление клавиатурой, ссылки автора и выпусков, сохранение
вкладки после смены языка и ошибка получения версии. Скриншоты просмотрены.
Нативная приёмка нового оформления и окончательной истории продолжается.

## Интеграция телефона, VPN и восстановления — 22 ноября

Пользователь разрешил параллельную работу агентов и снова подтвердил полный
перенос всех отсутствующих изменений, включая исправления и оформление.
Root объединяет изменения в одной рабочей папке и собирает EXE централизованно.

В основной интерфейс подключены локальная передача с телефона, QR и подтверждение
на ПК, состояния и уведомления, отправка с полки и отдельная зона перетаскивания.
Поздний стартовый снимок не заменяет новые события телефона/полки. Ожидание
подтверждения удерживает панель, Escape по-прежнему закрывает её. Для обычных
файлов добавляются время и происхождение; старые записи не переписываются.
Новая ступенчатая композиция полки ещё отдельно дорабатывается агентом.

Подключены выбор VPN-клиента, последовательное отключение прежнего клиента,
наблюдение нового туннеля или прокси и полное отключение VPN-модуля. Исправлена
гонка обработчика `vpn:update` при пустом состоянии, закрывается открытый выбор
при отключении модуля. Настоящие VPN-соединения пользователя не переключались.

Watchdog включён в setup/shutdown и IPC. Нативная проверка окна и ответа main
webview учитывает сон, стартовую задержку, лимиты восстановления и активные
запись/диктовку/установку/передачу файлов. Проверка зависания будет выполняться
только в отдельной копии с изолированным профилем.

Ошибка «Сохранить как» воспроизведена на предыдущем EXE: обычный final-name
файл объявлялся завершённым, пока writer ещё держал его открытым. Source
исправлен; новый Rust regression прошёл. Это наш отдельный процесс-писатель,
не настоящий браузер пользователя. Нативный regression новой EXE ещё впереди.

Проверки этого снимка: 193 IPC-команды / 152 настройки; frontend build прошёл,
134 JS-теста прошли, 207 интегрированных Rust-тестов прошли. Release build
продолжается. Эти результаты ещё не являются общей приёмкой полного переноса.

Начаты модель праздников, эффекты снега/шапки/гирлянды и компонент настроек.
Три теста календаря и политики эффектов прошли, TypeScript прошёл. Эти модули
пока не подключены к основной странице: нативная поверхность снега поверх
окон и её проверки остаются в работе. Общий список выпусков не закрыт.

- **«О приложении» и «Что нового» (1.4.0):** подготовлены канонические release notes `releases/1.4.0/release.json` и `RELEASE_NOTES_1.4.0.md`, добавлен компонент `WhatsNewShowcase` (интерактивные живые превью Woods Island для 5 ключевых функций, включая живых сезонных персонажей + ленивая подгрузка MP4 через команду `whatsnew_clip` с кэшем и поддержкой `prefers-reduced-motion`).

и обновления сайта пока нет; владелец сначала получает готовое приложение для
просмотра. Текущая опубликованная версия остаётся 1.3.1.

- Phone/shelf: добавлены настоящие ограниченные PNG/JPEG/WebP-превью, нативные

  при остановке/обновлении ссылки. Браузерная проверка двух языков/тем и

  указано, где одобрить новые хуки. Отдельный нативный host и настоящий

  сканер и кнопки разрешений полного Tauri-приложения.
- Персонажи: пять собственных праздничных рисунков; сохранены 11 Woods и
  девять необязательных Codex-питомцев. Проверены все 26 SVG-персонажей,
