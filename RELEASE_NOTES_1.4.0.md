# Woods Island 1.4.0

Крупное обновление функциональности, оформления и надёжности Woods Island — все возможности доступны бесплатно.

- Телефон по QR-коду без сторонних серверов: отправка фото, файлов и текста по локальной сети на полку и в буфер, отправка файлов с полки на телефон. Ступенчатая полка с миниатюрами PNG/JPEG/WebP, нативными значками файлов и происхождением.
- Раздел «Праздники»: снег из-под пилюли, снежная шапка, гирлянда в такт музыке, расписание по датам, отдельный экранный снег без мигания и пять авторских новогодних персонажей Woods рядом с питомцами.
- Режим выреза, как на MacBook: резервирование полосы у верха экрана (Чёрная, Стекло или Обои), чтобы развёрнутые окна начинались под островом.
- Погода для нескольких городов с быстрым переключением и плавными анимациями значений.
- ChatGPT во вкладке «Чат» рядом с Gemini и DeepSeek, текущая дата в запросах ИИ, понятные ошибки и HTTP/SOCKS5-прокси с защитой пароля через Windows DPAPI.
- Хуки Codex через hooks.json без перезаписи чужой команды notify, исправления PowerShell для Claude Code и поддержка OpenCode с ответами прямо с острова.
- Плееры AIMP и Winamp, правильные имена браузерных приложений и Firefox, захват звука конкретного плеера для визуализации (включая микшеры вроде Sonar и Voicemeeter) и скрытие лишних плееров.
- Напоминания с датами словами на русском и английском, сдвиги времени, состояние «внимание» у персонажа, голосовые команды и обновлённый рекордер сочетаний клавиш.
- Список VPN-клиентов с последовательным переключением и определением собственного туннеля или прокси.
- Уведомления программ со значками, фильтр торрент-загрузок, исправление «Сохранить как» в браузерах, улучшенный редактор скриншотов и чтение декоративных/светлых QR-кодов.
- Автовосстановление при зависании интерфейса, системный трей с возвратом острова и автовозврат, если окно спрятала другая программа.
- Обновлённые разделы «О приложении» и «Что нового» с интерактивным обзором и поддержкой коротких клипов.

Setup сохраняет настройки. Portable обновляется вручную после закрытия острова.

---

Major feature, design and reliability update for Woods Island — every feature remains free.

- Local QR phone transfer with no third-party servers: send photos, files and text over your local network to the shelf and clipboard, and push files back to your phone. Tiered shelf with PNG/JPEG/WebP thumbnails, native file icons and origin metadata.
- Holidays section: local pill snow, snow cap, music-reactive garland, annual date schedules, flicker-free full-screen snow and five original seasonal Woods characters alongside all pets.
- MacBook-style notch mode: reserves a top strip (Black, Glass or Wallpaper) so maximized windows start cleanly below the island.
- Multi-city weather with one-click switching and smooth animated values.
- ChatGPT alongside Gemini and DeepSeek, current date context in AI prompts, clear localized errors and HTTP/SOCKS5 proxy support with Windows DPAPI credential storage.
- Codex hooks via hooks.json without overwriting foreign notify commands, Claude Code PowerShell fixes and OpenCode support with inline permission replies.
- AIMP and Winamp support, proper browser PWA and Firefox names, per-player WASAPI process loopback (including Sonar and Voicemeeter mixers) and hidden player filtering.
- Natural-language reminders in Russian and English, time shift controls, attention character mood in timer/reminder cards, voice commands and an improved shortcut recorder.
- VPN client picker with sequential switching and custom client tunnel/proxy tracking.
- Native app notification icons, torrent download filter, browser Save As completion fix, improved screenshot editor and decorative/inverted QR decoding.
- Watchdog auto-recovery on interface hangs, Woods system tray menu and automatic window restore when hidden by another program.
- Redesigned About and What's New sections with an interactive feature showcase and lazy MP4 clip support.

Setup preserves preferences. Portable updates manually after closing the island.
